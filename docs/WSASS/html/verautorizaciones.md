# CÓMO VER LAS AUTORIZACIONES REALIZADAS[¶](#como-ver-las-autorizaciones-realizadas "Enlazar permanentemente con este título")

MENU

Opción: “Autorizaciones” para ver las autorizaciones realizadas.

De cada autorización se muestra:

1. Dador. Es la CUIT de quien realizó la autorización.
2. Alias. Es el alias del certificado autorizado.
3. Representado. Es la CUIT que puede acceder al servicio.
4. Servicio. Es el identificador del servicio autorizado.

Pulsar en el enlace “Eliminar” para mostrar los detalles de una autorización en particular, con opción a eliminarla. La eliminación de una autorización no elimina al certificado vinculado a la misma.
