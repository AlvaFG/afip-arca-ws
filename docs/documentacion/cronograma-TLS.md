# Web Services SOAP

## Cronograma de implementación de TLS V1.2

Las versiones de TLS (v 1.0 y 1.1) serán discontinuadas debido a que resultan versiones obsoletas y sujetas a riesgos de seguridad. Se ruega a los usuarios realizar las adecuaciones necesarias de sus servicios webs y aplicativos al protocolo TLS v1.2, ya que podrían verse afectados por estas actualizaciones.
