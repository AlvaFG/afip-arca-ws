# Web Services SOAP

## Autoridades certificantes reconocidas

La siguiente lista muestra a las autoridades certificantes reconocidas y utilizadas por ARCA para servicios SSL/TLS. Verifique que las mismas se encuentren incluidas en las aplicaciones clientes que utilizan los WS del organismo.

- [Geotrust Inc.](https://www.geotrust.com/)
- [Digicert Inc.](https://www.digicert.com/)
- [Sectigo](https://www.sectigostore.com/)
- [Global Sign](https://www.globalsign.com/es/)
- [SSL Corp.](https://www.ssl.com/repository/)
