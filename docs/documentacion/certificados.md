# Web Services SOAP

## Certificados para testing/homologación

Para los programadores que quieran probar sus aplicaciones que consuman de los servicios web de ARCA, se dispone del WSASS, una aplicación web que permite al programador gestionar sus certificados para nuestro entorno de testing. El servicio se debe solicitar desde el [Administrador de Relaciones de Clave Fiscal](https://auth.afip.gov.ar/contribuyente_/login.xhtml?action=SYSTEM&system=adminrel), al que habrá que ingresar con la clave fiscal de una persona física (no de persona jurídica).

### Certificados para producción

Los certificados digitales para el ambiente de producción se gestionan mediante las aplicaciones web “Administración de Certificados Digitales” y “Administrador de Relaciones de Clave Fiscal”, disponibles [autenticándose con clave fiscal](https://auth.afip.gob.ar/contribuyente_/login.xhtml).
